# THSV StreamBridge downloads

This is where official THSV StreamBridge releases are published. Download the newest
`THSV-StreamBridge-<version>.zip` from the [latest release](https://github.com/surakage/THSV-StreamBridge-Releases/releases/latest),
or use the [SlothBloom download link](https://www.slothbloom.com/downloads/streambridge), which points to the same file.

- **Setup guide:** [Quick start](docs/guide/quick-start.md) and [Install and first run](docs/guide/install-and-first-run.md)
- **Report a bug or give feedback:** [open an issue](https://github.com/surakage/THSV-StreamBridge-Releases/issues/new/choose)
- **Check a download:** [Release verification](RELEASE-VERIFICATION.md)

Every release is built by this repository's [release workflow](.github/workflows/release.yml), and
GitHub signs where each archive was built. Installed copies of StreamBridge check that signature
before they update.
